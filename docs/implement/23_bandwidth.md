# 23 — `[bw]` 대역폭 / 큐잉 구현 보고서
> 커밋: `2345eda` 모델 · `083acd0` 벤치 · `6309804` 문서
>
> **1단계(기계 완성)가 닫혔다.** 이 저장소가 첫 표부터 들고 있던 질문에 답한다 —
> *지금까지의 수치가 "천장이 없다"는 것에 기대고 있었나?*

## 세 번째 축

```
MemoryModel      접근이 발행 용량으로 얼마인가
LatencyModel     하나가 얼마나 기다리는가
BandwidthModel   둘이 서로에게 무엇을 하는가          ← 새로
```

**기본값은 꺼져 있다.** 앞의 둘이 그랬듯, 켜야 켜진다 — 기존 표가 안 흔들린다.
그리고 **지연 모델 없이는 아무 일도 안 한다**: 아무도 안 기다리는 큐는 큐가 아니다.

### 무엇이 줄을 서나

**메모리까지 가는 것만.** 이미 칩 위에 있는 라인은 칩 위에서 답한다. 온칩 경로에도
천장을 주면 **측정이 뒷받침할 수 있는 것보다 많은 주장**을 하게 된다.

서버는 **고정 서비스 시간의 단일 큐**다. 포화할 수 있는 가장 단순한 것이고, 읽는
사람이 돌려보지 않고도 거동을 예측할 수 있는 유일한 것이다.

`memory_free_at_` 은 **1/lines_a_cycle 사이클 단위**로 센다. 사이클당 8 라인이
0 으로 반올림되지 않게 정수 산술로 정확히 유지하기 위해서다.

**런치 사이에 비운다.** 캐시의 상주는 안 비우는데 이건 비운다 — 하나는 **쓰고 있는
자원**이고 다른 하나는 **기억하고 있는 것**이다. 이걸 고정하는 테스트가 캐시를 먼저
비워야 했다: 안 그러면 두 번째 런치가 전부 히트라 메모리에 닿지도 않는다.

`memory_lines_a_cycle` 은 상수가 아니라 **머신 파일의 knob** 이다. 이 모델의 요점이
"커널이 원하는 것보다 작으면 어떻게 되나" 이므로.

## 나온 것

### ① 기전 — 여덟 워프가 스트리밍 (라인 2,048 개)

| 사이클당 라인 | 사이클 | 큐 대기 | |
|---|---:|---:|---|
| 천장 없음 | 3,416 | 0 | — |
| 8 | 3,399 | 6,720 | 1.00x |
| 1 | 3,806 | 59,520 | **1.11x** |

**큐가 생겼다고 느려지지 않는다.** 사이클당 8 라인에서 요청들이 6,720 사이클을
서로 기다리는데 커널은 같은 시간에 끝난다 — 워프는 어차피 메모리를 기다리고 있었고,
**다른 것이 날아오는 동안 조금 더 기다리는 것은 공짜다.** 천장이 커널이 요구하는
것보다 낮아져야 시계가 움직인다.

### ② 렌더러 — 한 사이클도 안 움직인다

| SM | 천장 없음 | 8 라인/사이클 | |
|---:|---:|---:|---|
| 8 | 10,553 | 10,553 | **7.66x** (둘 다) |
| 32 | 9,593 | 9,593 | **8.42x** (둘 다) |

**수요가 전부다.** 스트리밍 워프가 사이클당 **0.60 라인**을 요구하고 렌더러는
**0.02** 다 — 서른 배 차이. 천장은 **커널이 요구하는 것보다 낮을 때만** 물리고,
사이클당 8 라인은 둘 다보다 위다.

## 이걸로 정해진 것과 안 정해진 것

**정해진 것.** README 가 처음부터 "가장 중요한 셋" 1번으로 적어온 질문 — *이 저장소의
스케일링 수치가 대역폭 벽을 숨기고 있었나?* — 의 답은 **아니오**다. 여기서 재는
커널들은 천장에 닿을 만큼 메모리를 안 부른다.

**안 정해진 것.** 이건 실제 기계의 대역폭 모델이 아니다:
- 큐 하나, 서비스 시간 하나
- 읽기와 쓰기 트래픽을 구분하지 않는다
- row buffer 가 없다
- **온칩 경로는 여전히 무제한**이다

**답할 수 있는 것은 "다른 수치가 천장의 부재에 기대고 있었나" 뿐이고, 그것만
주장한다.**

## 벤치마크가 두 씬을 필요로 했다

**기전 표는 여기 있는 어떤 커널보다 많이 요구하는 커널이 필요했다** — 그래서
합성이다. 블록마다 자기 영역을 읽는다(안 그러면 두 번째 워프가 첫 워프의 라인을
찾아서 메모리에 아무것도 안 부른다).

**렌더러 표는 반대가 필요했다** — L1 을 16 라인으로 줄여야 씬이 **미스라도 한다.**

둘 다 절에 적었다. 조용히 배치하면 그게 결과처럼 읽힌다.
