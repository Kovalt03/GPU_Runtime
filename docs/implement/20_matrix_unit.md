# 20 — `[m6]` 행렬 유닛 구현 보고서
> 커밋: `adf1aa2` 명령 + 지연 버그 · `22bbadd` 벤치 · `6492f58` 문서

> 2020 년대 GPU 를 정의하는 것. `V_MATVEC_MAT4_F32`(비용 16) 이 그 장난감 버전이었고,
> `DOC/01` 의 확장 계획이 `MAT4` 자리를 비워둔 이유이기도 하다.

## 만든 것

```
V_MMA_16X16X16_F32   reg[dst..+7] += A(reg[src0..+7]) * B(reg[src1..+7])
```

**피연산자가 레인의 레지스터가 아니라 워프의 레지스터인 첫 명령이다.**
`V_SHUFFLE_F32` 도 레인을 넘나들지만 레인마다 하나씩 계산한다. 이것은 **어떤 레인도
혼자서는 시작할 수 없다** — A 의 한 행도, B 의 한 열도 한 레인에 없다.

그래서 `is_warp_level` 에 들어가고, 참여 마스크가 32 레인 전부가 아니면 **거부한다.**
부분 결과가 아니라 틀린 결과가 나오는 종류라서다.

### 형태와 배치

```
16×16 = 256 원소,  워프 32 레인  →  레인당 8 레지스터
A + B + 누산기 = 24 레지스터     (파일은 256)
레인 L 이 L*8 부터 8 개.  행이 16 이므로 레인 2r, 2r+1 이 행 r 을 나눠 갖는다
```

**설명 가능한 것을 골랐다.** 하드웨어의 fragment 배치는 데이터패스가 고르고, 그걸
흉내 내도 이 모델이 말할 수 있는 것이 늘지 않는다.

`<SHAPE>` 토큰이 다섯 번째 형태로 늘었다 — 타일은 **자기 치수로 읽는다**(`16X16X16`).
`MAT16` 같은 이름은 수가 셋이라는 것과 셋이 같을 필요가 없다는 것을 숨긴다.

### 값을 정한 방식

`reduction_bench` 가 셔플에 쓴 방법 그대로다. **가격을 정해놓고 재면 그 가격을 되받아
읽을 뿐이므로**, 뒤집어서 묻는다 — *얼마여야 두 경로가 비기나?*

```
한 타일 = 레인당 128 MAC.  →  비기는 값은 128
지금 매긴 값 16            →  "행렬 유닛이 산술 파이프보다 8 배 빠르다" 는 주장
```

8 배는 하드웨어 텐서 코어가 인용되는 범위(8~16 배)의 **보수적인 끝**이다. 표에서
세는 것(명령 수·워프 스텝·사이클)과 주장하는 것(비용)이 갈려 있다.

## 나온 것

| 타일 | 경로 | 명령 | 워프 스텝 | 레인 연산 | 사이클 |
|---:|---|---:|---:|---:|---:|
| 1 | fma | 129 | 129 | 4,128 | 513 |
| 1 | **mma** | **2** | **2** | **544** | **33** |
| 16 | fma | 2,049 | 2,049 | 65,568 | 8,193 |
| 16 | **mma** | **17** | **17** | **8,224** | **513** |

**명령 수는 주장이 아니다.** 레인당 128 MAC 대 명령 하나 — 형태가 그렇게 정해준다.

## 세 opcode 전부터 있던 버그를 찾았다

워프 수준 경로(ballot / any / all / shuffle, 그리고 이제 MMA)가 **지연을 설정하지 않고
빠져나가고 있었다.** 그래서 워프 프리미티브는 **직전 명령이 우연히 낸 지연**으로
과금되고 있었다.

행렬 유닛에서 드러났다 — 32 사이클 깊이인데 **1 사이클**로 나왔다.

고치니 `[m9]` 에서 방금 낸 값들이 움직인다:

| | 전 | 후 |
|---|---:|---:|
| 워프 하나, 셔플 5 회 | 129 | **149** |
| 셔플 + 원자 | 343 | **363** |
| 레인당 원자 대 셔플+원자 | 3.3x | **3.1x** |

**결론은 안 움직였다.** `RESULTS.md` 에서 이 opcode 들을 건드리는 표는 리덕션뿐이다.

## 검증

- `ctest` **316/316** — 스케줄러 5 개 신규
- **호스트 레퍼런스와 일치** — 같은 배치로 16×16×16 을 호스트에서 풀어 대조한다.
  대칭이 아닌 값으로 채운다: 대칭 행렬이면 전치 실수가 통과한다
- **누산한다** — 같은 레지스터로 두 번 돌리면 32(=16×2)
- **전원 참여** — 절반 마스크는 거부
- **조각이 파일 안에 있어야** — 252 에서 8 개는 끝을 넘고, 17 은 4 의 배수가 아니다
